# What is published, and what is not

Generated by `node scripts/export-repo.js`. The script list is worked out by
following `require()` from the tools, so nothing is included by habit and
nothing needed can be left out by mistake.

## Published

| What | Files | Why |
|---|---|---|
| `scripts/` | 6 | the command line tool, and nothing else |
| `checks/` | 9 | the harnesses behind every report and example |
| `patterns/table-format.schema.json` | 1 | the format, written as a JSON Schema |
| `patterns/omc/omc-v2.6.json` | 1 | the largest schema, which build-all reads |
| `samples/PINNED.json` | 1 | what each schema hashed to when it was pinned |
| `samples/real/` | 6 | the six schemas every number is measured against |
| `samples/stress/` | 18 | seventeen more, chosen to break things |
| `reports/` | 5 | only reports a script in this repository regenerates |
| `examples/` | 6 | the worked example and the index |
| `examples/pages/` | 23 | all 23 schemas rendered as pages |
| `examples/markdown/` | 23 | the same 23 as Markdown, which GitHub renders in place |
| `README.md, package.json` | 2 |  |

## Left behind

- **`build/`** (13MB, 124 files). Generated. `npm run build` recreates it.
- **`HANDOVER.md`**. A checklist written to ourselves about what to run and
  what to send. Not something a reader of this repository needs.
- **`docs/`**. A plain-English tour written for our own use. The README and
  `examples/` are what a reader of this repository needs.
- **`designs/`, `LAB.md`, and the rest of `patterns/`.** Research notes, the
  draft-3 test suite, a pattern gallery, MovieLabs PDFs. All of it is how we
  got here, none of it is the thing itself.
- **25 scripts** nothing published depends on:
  `ablate`, `build-gallery`, `canonicalize-patterns`, `compare-json-vs-table`, `compare-omc`, `curate-catalog`, `dependencies-collapsing-strategies`, `dependencies-flat-shapes`, `export-repo`, `extract-patterns`, `final-report`, `generate-docs`, `generate-docs-table`, `generate-docs-v1`, `make-report`, `omc-graph`, `omc-model`, `omc-reconstruct-score`, `omc-ref-census`, `omc-to-draft3`, `page-to-text`, `reader-scores`, `ref-cases-genuine`, `reports`, `score-any`

Those scripts are earlier attempts and one-off investigations: three
abandoned generators, the pattern extraction that produced the catalogue, the
dependency-collapsing experiments, and the OMC reference census. They are kept
in the lab and are not part of the tool.
